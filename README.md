# **Data Mining Project - Network Intrusion Detection**
### **Course: Fundamentals of Data Mining (2025)**  
**University:** Islamic Azad University, Shiraz Branch  

---

## **Project Overview**
This project focuses on analyzing network traffic data to identify and predict anomalies and potential security threats. The **KDDCup99** dataset is used for training and testing machine learning models, with a special focus on clustering and classification methods.  

Key objectives:
- Preprocessing network traffic data for cleaning and normalization.
- Clustering data using the **DBSCAN** algorithm.
- Building a decision tree model (**C4.5**) for classification.
- Visualizing and interpreting results for anomaly detection.

---

## **Dataset**
- **Name:** KDDCup99 Dataset
- **Source:** [KDDCup99 Official Website](http://kdd.ics.uci.edu/databases/kddcup99/kddcup99.html)
- **Description:** A benchmark dataset for anomaly detection in network traffic.
- **Features:**
  - Total Records: 494,021
  - Total Features: 42
  - Labels: Normal connections and 23 types of attack connections.

---

## **Technologies Used**
- **Software:** RapidMiner
- **Algorithms:**
  - DBSCAN (Density-Based Spatial Clustering)
  - Decision Tree (C4.5)
- **Visualization Tools:** Scatter Plot, Confusion Matrix

---

## **Steps Performed**
1. **Data Preprocessing:**
   - Removed duplicate and incomplete records.
   - Normalized numerical features to a 0-1 range.
2. **Clustering with DBSCAN:**
   - Parameters:
     - eps: 0.5
     - min_samples: 5
   - Identified clusters and noise points.
3. **Classification with Decision Tree:**
   - Split dataset into training (80%) and testing (20%).
   - Evaluated model accuracy, precision, and recall.
4. **Results Visualization:**
   - Scatter plot for cluster distribution.
   - Confusion matrix for classification evaluation.

---

## **Results**
- **Clustering:**
  - Number of clusters: 3
  - Noise points: 15% of data
- **Decision Tree Performance:**
  - Accuracy: 92%
  - Precision: 89%
  - Recall: 91%
